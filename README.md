# responsive_design
For the tablet view, we adjusted the text and image styles, sizes, and layout to fit the screen properly. For the mobile view, we changed the text styling to make the content easier to read and more suitable for smaller screens.

Files Used

- index.html
- style.css
- logo.png
- Side_Image.png


How to Run

1. Download the project files.
2. Open the project folder.
3. Double-click `index.html`.

The website will open in your browser.
