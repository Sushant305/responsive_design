# Laundry Service Website

This is a simple Laundry Service landing page created using HTML and CSS.

## About the Project

This website is designed for a laundry service business. It contains:

- A navigation bar
- Company logo
- Hero section
- Service description
- Call-to-action button
- Laundry service image

The website is responsive and works on desktop, tablet, and mobile devices.

## Technologies Used

- HTML
- CSS

## Files Used

- index.html
- style.css
- logo.png
- Side_Image.png

## What I Learned

While building this project, I practiced:

- HTML page structure
- CSS styling
- Flexbox layout
- Responsive design
- Navigation bar design
- Buttons and hover effects
- Working with images

## How to Run

1. Download the project files.
2. Open the project folder.
3. Double-click `index.html`.

The website will open in your browser.
